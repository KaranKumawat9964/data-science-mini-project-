 A Data Science mini project using Python, Pandas, Matplotlib, and Seaborn to analyze student performance, study time, absences, and final grades through data analysis and visualization.
# 📊 Student Performance Analysis – Data Science Mini Project

## 🚀 Project Overview

This project analyzes student academic performance using Python. It explores the relationship between study time, absences, and final grades to identify useful patterns in student performance.

## 🎯 Objectives

* Explore and understand a real-world dataset.
* Perform data analysis using Python.
* Create visualizations to identify patterns.
* Generate meaningful insights from the data.

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab
* Jupyter Notebook

## 📂 Dataset

**Source:** [UCI Student Performance Dataset](https://archive.ics.uci.edu/dataset/320/student+performance)

The dataset contains information about students, including study time, absences, and academic grades.

## 📈 Project Workflow

1. Import the required Python libraries.
2. Load and explore the dataset.
3. Check dataset information and missing values.
4. Calculate descriptive statistics.
5. Visualize study time versus final grades.
6. Analyze absences versus final grades.
7. Create a correlation heatmap.
8. Summarize the findings.

## 🔍 Key Analysis

* Average, minimum, and maximum final grades.
* Study time categories and academic performance.
* Absences and final grades.
* Correlations between previous and final grades.

## ▶️ How to Run

1. Open the notebook in Google Colab.
2. Run each code cell in order.
3. View the generated charts and statistical results.
4. Review the findings at the end of the notebook.

## 📌 Conclusion

This project demonstrates the use of Python for data exploration, statistical analysis, and visualization. It provides practical experience in discovering patterns in student academic data.

**Note:** Correlation does not necessarily mean causation. Interpret the results based on the actual analysis.
